# 运输业务一体化客户端

将原有“运输证查询回填工具”和“爱企查批量查询工具”整合为一个 PyQt5 桌面客户端，并加入账号权限与可扩展数据统计。

## 已实现功能

- 统一登录和主界面。
- 管理员、普通用户两种身份。
- 首次启动自动创建管理员，首次登录强制修改密码。
- 账号包含“用户名称”和登录账号，管理员可创建账号、重置密码、启用/停用账号；密码最低 6 位。
- 单一“一键业务处理”界面，不再在两个工具页面之间切换。
- 一个按钮依次完成：运输证号查询 → 营运企业回填 → 爱企查法人/地址/电话补齐。
- 保留数字验证码、中文点选验证码、网站登录和人工录入等原有处理能力。
- 统一选择一次 `.xlsx` 表格，三个步骤都在原表上继续处理并保存。
- 数据预览表格随任务实时刷新：前两步跟踪 Excel 写入，爱企查逐行直接更新。
- 提供整体进度、三步独立状态、统一日志、暂停、继续和停止控制。
- 首屏数据仪表盘提供“站点 + 数据分类”双下拉筛选：完成类型查看六分类，违规类型查看“原因”拆分及有电话/其他数据统计。
- 选择“按违规类型”后，计量条区域上方会显示“切换为原因占比”按钮：默认显示满宽的有电话/其他数据双色拆分；占比模式与完成类型计量条一致，条长表示该原因占全部原因条目的比例，条尾显示总条数和百分比，再次点击可恢复电话拆分样式。
- 仪表盘的“图表分析”“完整数据”“最近统计记录”使用三个标签页切换，顶部筛选和指标卡保持常驻并同步刷新三个标签页的数据。
- 图表分析中的环形图会根据可用空间放大至约 190 像素；悬停扇区时对应色块会浮出，并通过专门设计的深色悬浮信息卡显示名称、数量、占比及电话拆分等详细信息。信息卡使用与当前数据对应的彩色强调条，以独立浮层显示，不受图表窗口尺寸裁切，并会根据当前显示器可用区域自动翻转位置；四项详情采用两列两行紧凑布局，避免卡片高度随详情类型明显变化。计量条加粗为 10 像素并带有轻量循环流光效果。
- 统计直接显示在仪表盘，不设置重复的“后台统计”导航。
- 统计指标和事件分离，便于后续增加新的统计内容。
- 退出/注销时停止当前流水线，并保存已经取得的爱企查结果。

## 推荐环境

原两个工具的可用环境均为 Python 3.9.13，因此建议使用 64 位 Python 3.9。

```powershell
py -3.9 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

也可以双击 `run.bat`，它会优先使用项目内 `.venv`。

## 数据保存位置

Windows 默认位置：

```text
%LOCALAPPDATA%\IntDemoClient\client.db
```

数据库保存账号、密码哈希、角色、状态和统计事件，不保存明文密码。可通过环境变量 `INTDEMO_DATA_DIR` 修改数据目录。

## 统计口径

- 只有运输证查询、营运企业回填、爱企查补齐三个步骤全部成功并保存结果后，才统计本次表格；失败或人工停止不计数。
- `总计数`：本次完整流程处理的表格数据行数。
- `空`：车辆所有人/企业为空，或未形成有效公司名的数据行数。
- `无运输证号`：存在待分类信息，但最终没有有效运输证号的数据行数。
- `无营运信息`：营运车辆查询明确返回“无营运信息”的数据行数。
- `个体经营`：营运信息结果为个体经营或个人经营的数据行数。
- `无电话（有公司名）`：有有效运输证号和公司名称，但没有有效电话号码的数据行数。
- `有电话（有公司名）`：有有效运输证号和公司名称，并取得有效电话号码的数据行数。

六个分类互斥，满足：`总计数 = 空 + 无运输证号 + 无营运信息 + 个体经营 + 无电话（有公司名） + 有电话（有公司名）`。旧版分步骤和三分类指标停止展示和写入，既有历史记录仍保留在数据库中；新六分类口径从本次升级后独立累计。

“按违规类型”读取完成表格中的 `原因` 列，按 `|`、`｜`、`/` 或 `／` 拆分多个原因。同一行可计入多个原因，但同一行内重复原因只计一次；每个原因分别显示总计、有电话和其他数据，其中“有电话”沿用上述“有电话（有公司名）”口径。违规原因采用环形图和满宽双色堆叠条，绿色表示有电话、橙色表示其他数据，条尾仅显示总条数；只有鼠标悬停计量条时显示有电话/其他数据数量，下方明细表保留完整数据。

新增统计项目时，只需增加指标定义并写入事件，不需要修改账号表或既有统计数据。

## 测试

```powershell
$env:QT_QPA_PLATFORM='offscreen'
python -m unittest discover -s tests -v
```

离线测试覆盖账号、权限、密码、统计、统一主窗口装配、实时表格模型、三步自动衔接和 Excel 结果回写。两个查询网站仍需使用真实账号、真实测试表和当前网络环境执行验收，因为验证码、页面选择器及网站策略可能随时变化。
