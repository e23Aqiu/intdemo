# 验证码机器学习

## 适用范围与上报策略

该功能仅用于已取得网站及数据处理授权的环境。管理员侧边栏的“机器学习”页面
控制全体在线客户端的上报方式，服务端首次部署及数据库迁移后默认关闭：

- `off`（关闭）：不上传任何验证码数据。
- `metrics_only`（仅统计）：只上传验证码类型、模型版本、成功/失败、是否人工
  协助和发生时间，不上传图片、答案或业务来源。
- `samples_and_metrics`（采集样本并统计）：记录上述统计；成功时还上传图片和
  答案，失败时仍不上传图片和答案。

客户端每 60 秒刷新策略；管理员切换策略或应用模型会增加策略修订号。旧版客户端
无法识别“仅统计”时会将其视为关闭，避免误传图片；升级后的客户端才会上报纯统计。

游客模式不会显示或启用该功能；服务端尚未部署对应接口或迁移时，客户端保持
默认关闭并在管理页显示读取失败。客户端不建立离线样本积压队列：断网或上传失败时
直接丢弃当次学习上报，不把验证码图片长期留在业务电脑中；瞬时后台任务达到
64 个时也会丢弃新的上报，避免无限重试挤占业务客户端内存。

## 采集规则

客户端只在验证码已经通过、并且后续业务结果确实返回后提交成功样本：

- 数字验证码：PNG/JPEG 图片及四位数字 `{"value": "1234"}`。
- 文字点选验证码：PNG/JPEG 图片、题目文字顺序和相对坐标（`x/y` 均为
  `0..1`），坐标不依赖客户端窗口尺寸。
- 自动识别和人工接管分别记录模型版本及 `assisted` 标记。
- “仅统计”不会为成功或失败尝试采集、编码或上传图片和答案。服务端根据验证码
  类型推导内部来源，仅保存类型、模型版本、是否人工、发生时间和成功/失败标记，
  不关联账号或设备，用于计算当前模型的线上成功率。
- “采集样本并统计”下，失败尝试同样不保存或上传图片和答案。
- 服务端按“类型 + 图片 + 标准化答案”的 SHA-256 指纹去重。重复成功尝试会计入
  线上成功率，但不会重复占用数据集空间。

单张图片上限为 1 MB。服务端仅接受 PNG/JPEG 文件签名、严格答案结构和受支持
来源；管理员操作会写入审计记录。

## 管理页面指标

- 数据集数量与占用空间：每 5 秒刷新，并分别显示数字和文字点选样本。
- 当前模型成功率：真实客户端尝试中，该模型版本的成功次数 / 尝试次数。
- 候选模型识别率：训练时固定、确定性的 20% 留出集结果，不包含后续线上尝试。
- 数字模型按四位数字全部一致才算一次正确。
- 点选模型按题目文字对应区域的完整序列全部一致才算一次正确；检测框仍由内置
  检测器提供，因此此数值不是端到端网页通过率。

样本量过少时训练按钮会提示：数字至少 20 张，文字点选至少 30 张。达到最低值
只代表可以执行训练，不代表模型已经适合生产应用；管理员应比较留出集准确率，
再在授权环境进行实际验收。为限制管理员电脑的训练内存和模型体积，单次每种类型
最多按样本指纹确定性选取 5000 张；候选模型指标会同时记录可用数与实际选取数。

## 模型生命周期

当前实现使用安全 NPZ 容器保存 `knn-pixels-v1` 像素特征模型，加载时禁用
pickle。训练先在管理员客户端本地完成，再将候选模型、样本数、留出集结果和
SHA-256 上传服务端。

候选模型不会自动影响业务。管理员选择“应用所选模型”后：

1. 同类型旧模型变为历史版本；
2. 新模型成为当前版本，策略修订号增加；
3. 客户端下载模型并核对 SHA-256；
4. 校验和解析均成功后才原子写入本机模型缓存并开始使用；
5. 下载或校验失败时继续使用内置 `ddddocr`，不会加载不可信模型。

当前应用模型不能删除；候选或历史模型可删除，样本数据不会随模型删除。管理员
也可按所选类型恢复内置 `ddddocr`，原自定义模型转为历史版本并保留，便于再次
应用或对比。客户端离线重启时可继续加载上次已校验的当前模型；重新连接并发现
管理员已恢复内置模型后，会清除“当前自定义模型”标记。

## 数据集导入与导出

管理员可导出全部数据，训练某一类型时客户端会请求该类型的 ZIP。压缩包结构：

```text
manifest.json
images/<sample-uuid>.png
images/<sample-uuid>.jpg
```

`manifest.json` 的 `schema_version` 当前为 `1`，每条样本包含：

```json
{
  "id": "UUID",
  "captcha_type": "numeric",
  "source": "transport_numeric",
  "image": "images/UUID.png",
  "image_mime": "image/png",
  "answer": {"value": "1234"},
  "model_version": "human-manual",
  "captured_at": "2026-07-30T10:00:00+00:00",
  "fingerprint": "SHA-256"
}
```

导入包上限为 100 MB（压缩前请求体及解压后内容均校验），拒绝路径穿越、超量
文件和无效清单。导入会重新检查图片签名、答案和指纹，不信任清单中的原始 ID
或指纹；页面会分别报告新增、重复和跳过数量。

## 接口

普通在线账号：

- `GET /api/v1/captcha/policy`
- `POST /api/v1/captcha/attempts`
- `GET /api/v1/captcha/models/{numeric|click}/current`

管理员：

- `GET /api/v1/admin/ml/overview`
- `PATCH /api/v1/admin/ml/policy`
- `GET /api/v1/admin/ml/dataset/export`
- `POST /api/v1/admin/ml/dataset/import`
- `POST /api/v1/admin/ml/models`
- `POST /api/v1/admin/ml/models/{id}/activate`
- `POST /api/v1/admin/ml/models/{numeric|click}/use-builtin`
- `DELETE /api/v1/admin/ml/models/{id}`

`PATCH /api/v1/admin/ml/policy` 使用
`{"upload_mode":"off|metrics_only|samples_and_metrics"}`。部署新版本后必须执行
Alembic `upgrade head`，以创建或升级验证码策略、尝试、样本和模型四张表。
数据库备份会随现有 PostgreSQL 全量备份流程包含这些数据；导出的 ZIP 仍应按
敏感授权数据加密保管。
